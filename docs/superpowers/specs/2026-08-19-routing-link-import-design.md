# Импорт правил по ссылке `happ://routing/onadd/<base64>`

Дата: 2026-08-19
Статус: утверждён

## Задача

В приложение Rule Flow Editor (Electron) добавить возможность импорта правил
из «ссылки маршрутизации» вида:

```
happ://routing/onadd/eyJOYW1lIjoiS2FsYm1hcFgtU21hcnQi...
incy://routing/onadd/eyJOYW1lIjoiS2FsYm1hcFgtU21hcnQi...
```

Такие ссылки приложение уже умеет **создавать** (кнопки «⚡ Happ» / «⚡ Incy»
в редакторе и конвертере, `buildRoutingLink` / `copyRoutingJson`).
Отсутствует обратное действие: вставить ссылку и получить правила.

Импорт должен работать и в редакторе, и в конвертере. Оба открывают одно
общее окно импорта (`#import-modal`), поэтому достаточно расширить это окно.

## Решение (подход А)

Добавить в окно импорта новую вкладку **«Ссылка»**. Пользователь вставляет
ссылку, жмёт «Импортировать» — правила декодируются и попадают в «Мои правила»
с разбивкой по секциям Direct/Proxy/Block, а поля `Geositeurl`/`Geoipurl`
конвертера заполняются значениями из ссылки.

## Изменения

### 1. `src/index.html` — вкладка в модалке импорта

Рядом с существующими вкладками `text` / `url` / `file` добавить:

- кнопку `.tab` с `data-tab="link"` и текстом «Ссылка»;
- панель `.tab-pane` с `data-pane="link"`, содержащую поле ввода
  `#import-link` (placeholder: `happ://routing/onadd/…`) и короткую подсказку.

Существующий переключатель вкладок (`document.querySelectorAll('.modal-tabs .tab')`)
уже обрабатывает новые вкладки автоматически, т.к. привязан к `data-tab` / `data-pane`.

### 2. `src/renderer.js` — декодирование и импорт

Новая функция:

```js
function decodeRoutingLink(text) {
  // 1) trim; попытка decodeURIComponent (ссылка могла быть URL-закодирована)
  // 2) если есть "routing/onadd/" — взять всё после последнего вхождения;
  //    иначе считать весь вход base64-полезной нагрузкой
  // 3) нормализовать base64url: '-' -> '+', '_' -> '/'; дополнить '='
  //    до кратности 4
  // 4) atob -> Uint8Array -> TextDecoder -> строка
  // 5) JSON.parse; проверить, что результат объект и не массив
}
```

Рефакторинг обработчика `#import-apply`:

- выделить общий путь импорта JSON в функцию `applyJsonImport(jsonObj, replace)`
  (существующая логика: `state.importedJson = jsonObj`, заполнение
  `#conv-src-geosite` / `#conv-src-geoip`, `parseJsonImport`, добавление правил
  чанками по 500, `syncMarks`, `updateRulesCount`, рендер списков конвертера,
  закрытие модалки, тост);
- в начале обработчика `#import-apply`: если активна вкладка `link` — вызвать
  `decodeRoutingLink($('#import-link').value)` и, при успехе, `applyJsonImport(...)`.

## Обработка ошибок

Тост с причиной, модалка **не закрывается**:

- пустое поле ссылки;
- ссылка не распознана (битый base64 / не JSON);
- в JSON нет ни одной из секций `DirectSites` / `DirectIp` / `ProxySites` /
  `ProxyIp` / `BlockSites` / `BlockIp`.

## Формат ссылки

Экспортируемая ссылка (уже реализовано): `scheme://routing/onadd/` +
стандартный base64 (с `+` `/` `=`) от UTF-8 JSON. JSON — полный конфиг
маршрутизации Happ: ключи `Name`, `GlobalProxy`, `RouteOrder`, DNS-настройки,
`DirectSites`, `DirectIp`, `ProxySites`, `ProxyIp`, `BlockSites`, `BlockIp`,
`Geositeurl`, `Geoipurl`, `LastUpdated`, `DnsHosts`, `DomainStrategy`,
`FakeDNS`, `UseChunkFiles`.

При импорте используются только секции правил и URL; остальные поля
сохраняются в `state.importedJson` для круглого экспорта (существующее
поведение пути JSON-импорта).

Разбор значений в секциях — существующая `parseLine`: `domain:` / `geosite:` /
`geoip:` / `regexp:` / `keyword:` / plain.

## Тестирование

Автотестов в проекте нет (нет тест-скрипта в `package.json`). Проверка вручную:

1. В редакторе собрать правила во всех трёх секциях, нажать «⚡ Happ»,
   скопировать ссылку.
2. Открыть окно импорта → вкладка «Ссылка» → вставить ссылку → «Импортировать».
3. Проверить: все секции импортировались, счётчики табов сходятся, поля
   `Geositeurl`/`Geoipurl` в конвертере заполнены.
4. «Экспорт JSON» / повторная генерация Happ-ссылки даёт тот же набор правил.
5. Негативные сценарии: пустая строка, обрезанная/битая ссылка, JSON без секций —
   показывается тост, модалка остаётся открытой.
